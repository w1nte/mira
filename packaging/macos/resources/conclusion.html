Mira is installed. Start it from the Applications folder or Launchpad.

Mira is not signed by Apple. If macOS says it cannot check Mira for malicious software, open System Settings → Privacy & Security and click Open Anyway next to Mira.

For properties and search, install Ollama as well. The command line is /Applications/Mira.app/Contents/MacOS/vision-tagger-cli.
